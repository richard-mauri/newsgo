# Current work — NewsGo

## Active draft — subscription failure details (Issue #55, November 8, 2026)

- **Issue:** [#55](https://github.com/richard-mauri/newsgo/issues/55); branch `fix/55-subscription-failure-details`; draft [PR #73](https://github.com/richard-mauri/newsgo/pull/73) against authoritative merged `main`.
- **Changes:** The existing Failure dialog shows the actual attempted feed endpoint and the validation error, with sensitive URL query values redacted and Retry preserved. **Find Subscriptions now prevalidates candidate feeds**, using the SSRF-hardened fetch path and existing RSS/Atom/RDF/JSON parser. The directory response labels candidates **Available** (readable entries), **Unavailable** (e.g., HTTP 400, 404, 410, unparseable/empty responses; Subscribe disabled), or **Not verified** (timeouts, 429, 503 and other uncertain results; Try Subscribe remains possible). The check is bounded to four simultaneous fetches, four seconds per request, nine seconds per search, twelve candidates, and two minutes of result caching. No automatic substitution of feed URLs or permanent blacklist.

- **Search presentation and unsubscribe (approved follow-up):** Confirmed-unavailable results are **hidden**, except when already subscribed, so a reader can remove an existing broken subscription. The count of hidden directory candidates is shown in the search summary; temporarily unverified feeds remain visible with Try Subscribe. In Find Subscriptions, already-followed feeds show a working **Unsubscribe** button rather than a disabled Subscribed button, with the existing confirmation dialog and shared `unsubscribeRecord` persistence. If the removed feed was selected for reading, its selection and stale article state are cleared without implicitly switching to Read All. The change respects publisher exclusions; successful Subscribe changes the search button to Unsubscribe without another search.
- **Scope preserved:** The existing Failure button, Close/Retry controls, independent category subscriptions, SSRF/feed validation, feed directory, per-user subscriptions, exclusions, preferences, credentials, server settings, cache, build counter and Cloudflare are unchanged. Stale error state is cleared on retry; failures are not automatically retried.
- **Evidence:** Screenshot on November 8 shows NBC News feeds with per-card Failure and status `Feed not added: HTTP 400`; Issue #55 also has an observed HTTP 503. Exact upstream cause not yet established; this PR improves diagnosis, not feed availability.
- **Tests:** Dialog/URL redaction and retry contracts, feed health classification (RSS success, HTTP 400/404/429/503, invalid markup, empty feed), concurrency bound, hidden unavailable feed behavior, confirmed Unsubscribe action, and existing catalog/exclusion behavior. Exact PR-head Go CI status to be recorded after run. Mac/Safari live publisher and UI acceptance remain outstanding.
- **Owner Mac acceptance:** `cd ~/projects/newsgo`, `git fetch origin`, `git checkout fix/55-subscription-failure-details`, `git pull --ff-only origin fix/55-subscription-failure-details`, `go test -count=1 ./...`, `./devbuild.sh`, `./newsgo.sh`. In Safari search NBC and verify HTTP 400 entries are omitted with a hidden count, working feeds show Subscribe, and uncertain 503s show Try Subscribe. A subscribed entry shows Unsubscribe; Cancel preserves it, Confirm removes it and updates My Subscriptions/reading selection, and re-subscribing changes it back to Unsubscribe. Test feed URL details in Failure dialog and confirm excluded publishers remain unchanged.
- **Merge boundary:** PR #73 remains draft until explicit owner approval; do not merge, tag, release or change `main`.
